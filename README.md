**Presentación del proyecto:**

El trabajo consiste en desarrollar una aplicación básica de inicio de sesión y creación de cuentas, con el propósito de introducir los conceptos necesarios para construir sistemas de este tipo. Para su elaboración se siguieron los videos explicativos incluidos en el formulario de entrega. Se utilizaron los siguientes programas y tecnologías: Visual Studio Code, phpMyAdmin, Apache y MySQL.

**Pasos para su instalación:**

1. Generar un directorio con el nombre "Login-register" en la ubicación C:\xampp\htdocs.
2. Colocar dentro de dicha carpeta todos los documentos descargados del repositorio.
3. Acceder a phpMyAdmin y cargar el archivo sql/db_login.sql mediante la opción de importación.
4. Iniciar los servicios Apache y MySQL desde el administrador de XAMPP.
5. Abrir un navegador e ingresar a la dirección http://localhost/Login-register.
